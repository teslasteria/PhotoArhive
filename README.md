# 📸 Photo Archive v1.0

**Простое приложение для сортировки фото по датам с поддержкой темной/светлой темы!**

![GitHub](https://img.shields.io/badge/license-MIT-green) ![Python](https://img.shields.io/badge/python-3.8+-blue)

---

## 🌟 Возможности (v1.0)

- 📂 **Сортировка фото по датам** (JPEG, PNG, HEIC и др.)
- 🗂 Автоматическое создание папок `ГГГГ-ММ-ДД` в выбранной директории
- 🌙 **Две темы**: светлая и темная
- 🚀 Простой интерфейс без лишних настроек

---

## ⚡ Быстрый старт

### Установка

1. Клонируйте репозиторий:

   ```bash
   git clone https://github.com/ваш-username/photo-sorter.git
   cd photo-sorter
   ```

2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

### Запуск

```bash
python main.py
```

_(или кликните на `start.bat` в Windows)_

---

## 🖥 Сборка (для разработчиков)

Если хотите собрать в EXE (используем PyInstaller):

```bash
pyinstaller --onefile --windowed main.py
```

Готовый файл появится в папке `dist/`.

---

## 📸 Как пользоваться

1. **Выберите папку с фото** → укажите исходную директорию.
2. **Выберите папку для сортировки** → куда сохранить отсортированные фото.
3. **Нажмите "Старт"** → приложение создаст папки по датам и скопирует туда фото.
